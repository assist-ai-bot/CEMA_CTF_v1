# Task 2 — Radio messages

`c2.bin` is a recording of the control radio. Messages follow one another with nothing between them.

The flag is the plain text of message id `0x0E`.

Submit it in this shape and no other. The word below is an example of the characters, not the message:

```
Intern_Pro_Max{red-kite}
```

Lowercase letters only, with one hyphen between the two words. No spaces.
