# Task 5 — Link budget

The flag is the fade margin in whole decibels, rounded to the nearest integer.

Submit it in this shape and no other. The number below is an example of the characters, not the margin:

```
Intern_Pro_Max{fm-3}
```

The letters `fm`, one hyphen, then the integer. No spaces and no decimal point.

| Input | Value |
| --- | --- |
| Transmit power | 20 dBm |
| Transmit antenna gain | 2 dBi |
| Receive antenna gain | 2 dBi |
| Frequency | 915 MHz |
| Distance | 1.8 km |
| Extra losses | 6 dB |
| Minimum usable receive power | −90 dBm |

Pencil on the sheet: frequency 0.915, free-space loss about 36.8, margin about 71.
