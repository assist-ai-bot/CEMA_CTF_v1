# Task 1 — Flight log

`sortie_014.dlog` is a copy of the drone's flight recorder.

The flag is the text stored in the valid record whose type is `0x17`.

Submit it in this shape and no other. The word below is an example of the characters, not the record:

```
Intern_Pro_Max{red-kite}
```

Lowercase letters only, with one hyphen between the two words. No spaces.
