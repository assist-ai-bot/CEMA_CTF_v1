# Task 7 — Memory dump

`core.dump` is a raw sequence of chunks from the companion computer.

The flag is the text from the accepted chunks, joined in index order. The accepted set is the one whose indexes are `0, 1, 2, ...` with none missing and none repeated.

Submit it in this shape and no other. The word below is an example of the characters, not the dump:

```
Intern_Pro_Max{red-kite}
```

Lowercase letters only, with one hyphen between the two words. No spaces.
