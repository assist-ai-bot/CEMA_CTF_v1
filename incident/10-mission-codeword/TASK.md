# Task 10 — Mission codeword

`codeword.elf` is a Linux x86-64 program from the flight computer. It still holds the codeword that was set before the drone was jammed over the Barmer sector.

The flag is the codeword the program releases when its check passes.

Submit it in this shape and no other. The word below is an example of the characters, not the codeword:

```
Intern_Pro_Max{red-kite}
```

Two lowercase words with one hyphen between them. No spaces.
